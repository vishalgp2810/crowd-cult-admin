## Deployment (Docker/GKE)

### Build image

```bash
docker build -t crowd-cult-admin:latest .
```

### Run container locally

```bash
docker run --rm -p 3002:3000 \
  -e NODE_ENV=production \
  -e PORT=3000 \
  -e NEXT_PUBLIC_API_URL=http://localhost:3031 \
  crowd-cult-admin:latest
```

### Environment variable matrix

- `NODE_ENV` - runtime mode (`production`)
- `PORT` - Next runtime port (`3000`)
- `HOSTNAME` - bind host (`0.0.0.0` in container)
- `NEXT_PUBLIC_API_URL` - backend API base URL consumed by browser requests
